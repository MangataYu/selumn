# Welcome diary image

`first-page.jpg` is the offline sample photo used by the first-install welcome
diary. It was created with the built-in ImageGen tool, then resized to 960 × 640
and JPEG-compressed (96,574 bytes). The diary caption identifies it as a generated
example image. Only the JPEG is included in the Flutter asset bundle.

Style/medium: Natural, realistic lifestyle photography with believable materials and subtle texture.

Lighting/mood: Warm soft natural window light; peaceful, intimate, inviting.
Constraints: Notebook pages are blank. No people, no text, no logos, no watermark.
